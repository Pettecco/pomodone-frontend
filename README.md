# PomoDone - Pomodoro Timer com To-Do List

**PomoDone** é uma aplicação de gerenciamento de tempo baseada na técnica Pomodoro. Você pode criar tarefas, configurar timers Pomodoro e acompanhar o progresso.

Este projeto está sendo desenvolvido em **React** para estudos pessoais. Esse repositório se trata do **frontend** da aplicação.

Para funcionamento completo do projeto é necessário rodar o servidor, localizado neste [repositório](https://github.com/Pettecco/pomodone-backend).

## Como Rodar o Projeto

1. Suba o servidor em sua máquina, localizado no repositório **pomodone-backend**.
2. Clone este repositório.
3. No terminal, execute os seguintes comandos:

   ```bash
   npm install
   
   # development
   npm run dev
   ```

Acesse a URL gerada e faça bom proveito :)
